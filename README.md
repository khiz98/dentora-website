# Dentora Dental Clinic (demo)

A responsive, static dental clinic website with Tajik, Russian, and English translations, sample services and staff, and an interactive appointment selection demonstration.

## Run locally
Open `index.html` in a browser. Alternatively run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish on GitHub Pages
1. Create a public GitHub repository called `dentora-website`.
2. Upload `index.html`, `style.css`, and `app.js` to the repository root (commit the files).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
5. Wait for deployment and open `https://YOUR-USERNAME.github.io/dentora-website/`.

## Important
All staff names, photos, contact information, prices, and schedules are fictional. Availability is generated locally; the form does **not** submit or store data. GitHub Pages does not provide a booking database. Before production, add a secure server/database, staff scheduling, authentication, privacy/consent, and atomic double-booking prevention. Replace all placeholder content.
